## 💡 Pharmacology Tip 1: The A–C Gout Reversal

When answering a basic gout question, remember this simple **A ↔ C reversal**:

### **A = C**

**A**llopurinol → **C**hronic gout control

Allopurinol lowers uric acid and is used as long-term urate-lowering treatment to prevent future gout attacks and joint damage.

### **C = A**

**C**olchicine → **A**cute gout attack

Colchicine reduces the inflammation caused by urate crystals and may be used to treat an acute gout flare.

### 🧠 Memory Formula

> **Allopurinol begins with A but points to Chronic.**
> **Colchicine begins with C but points to Acute.**

```text
A → C
Allopurinol → Chronic control

C → A
Colchicine → Acute attack
```

### 🎯 Examination Tip

If a basic examination question mentions:

* **Long-term uric-acid reduction or prevention of recurrent attacks** → think **allopurinol**.
* **Painful acute gout inflammation** → consider **colchicine**, alongside other guideline-recommended options.

### ⚠️ Important Exception

This mnemonic is a memory aid—not an absolute prescribing rule.

* Colchicine may also be used temporarily to prevent flares when allopurinol or another urate-lowering treatment is started or increased.
* If a patient is already established on allopurinol, it should not normally be stopped solely because an acute gout flare develops.
* Acute gout may also be treated with an NSAID or a short course of an oral corticosteroid, depending on the individual patient.

> **Final memory line: A crosses to C, and C crosses to A—but always check the clinical context.**
